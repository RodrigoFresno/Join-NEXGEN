# Genxsis.Faith — versão para GitHub Pages

Esta é uma versão estática e responsiva do site, preparada para publicação no GitHub Pages. O mesmo `index.html` adapta o layout para desktop e celular.

## Publicar no GitHub Pages

1. Extraia este ZIP.
2. Envie **todo o conteúdo desta pasta** para a raiz do seu repositório GitHub (não envie o ZIP como um único arquivo).
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Aguarde a publicação e abra o endereço exibido na página Settings → Pages.

O arquivo `index.html` está na raiz e os caminhos dos vídeos, imagens e áudio são relativos, compatíveis com GitHub Pages.

## Funcionalidades incluídas

- Botão inicial `Join NEXTGEN` com reprodução do áudio fornecido no pacote.
- Player de avisos: aviso 1 como padrão, acesso direto ao aviso 2 e seleção aleatória entre os avisos 3 a 7.
- `Avaliação` com perguntas, alternativas e textos de resultado traduzidos para português.
- `Redemption` reproduz aleatoriamente `coin.mp4` ou `Cross.mp4` em tela cheia, com botão para voltar.
- Clique em `pmginev1973.png` abre `darkside.jpg`.
- Rodapé: `© 2026 BMTH Entertainment recreated by @rodrigofresno`.

## Observação sobre nomes dos arquivos recebidos

O ZIP original contém `join the church of genxsis.mp3` (não `Join the Church of Jenkins.mp3`) e `key.png` (não `K.png`). Esta versão utiliza os arquivos que estavam efetivamente presentes no pacote. Se esses nomes se referirem a outros arquivos, substitua-os mantendo o caminho correspondente no `index.html`.
